# DAFC: Deadline-Aware Fault Containment for AI agent workflows on shared services

A research artifact: a seeded discrete-event **simulator** of LLM-agent workflows (DAGs) running on shared
endpoints (model, retrieval, tool, agent pools); the DAFC policy and its baselines; fault injection; and the
experiments, statistics, figures, and manuscript built from them.

**Evidence status:** simulation only. Agent outputs use a deterministic surrogate; no LLM, cloud, or
production system was used. Readiness is recorded in `reports/DAFC_FINAL_INDEPENDENT_VALIDATION_REPORT.md` and `reports/gate_status.md`.

**Zenodo artifact:** DOI `10.5281/zenodo.23305687` (reserved at preparation time; verify publication status before citing as a published record).

**License:** MIT; see [`LICENSE`](LICENSE).

## Layout

| path | contents |
|---|---|
| `src/dafc/` | `graph.py` (DAGs), `workload.py`, `faults.py` (fault injector), `simulator.py` (event engine), `policy.py` (DAFC), `baselines.py` (B0, B1, B1+, B1++, B1-OA, B1-ext, B1-IP, B2, ablations, registry), `metrics.py` (outcome classes from raw traces), `groundtruth.py` (independent checker), `stats.py`, `runner.py`, `config.py`, `rng.py` |
| `tests/` | unit, integration, and property tests (131 tests) |
| `configs/development/` | tuning grids (dev seeds 0–9) and superseded frozen parameters |
| `configs/holdout/` | frozen parameters and every experiment-set definition (holdout, sensitivity, robustness, addendum_a2, addendum_a3, confirmation, e123, e4, e123r, e5) and the frozen E4 frontier matching |
| `experiments/` | `tune.py`, `run_all.py`, `validate.py`, `analyze.py`, `confirm.py`, `diagnostics.py`, `posterior_accuracy.py`, `worked_example.py`, `tables.py`, `figures.py`, `reproduce_check.py`; studies E1-E4: `e123_verdicts.py`, `edge_probe.py`, `frontier_select.py`, `posterior_audit.py`, `e123r_identity.py`, `e4_verdicts.py`, `e5_arms.py`, `e5_verdicts.py`, `e4_exploratory.py`, `figure_e4.py`, `export_git_log.py` |
| `results/derived/` | one row per run (`<set>_runs.csv`), hypothesis verdicts, diagnostics, confirmation verdicts |
| `results/tables/` | per-cell summaries with CIs and pooled counts (`<set>_summary.csv`), paired tests (`<set>_paired.csv`) |
| `results/manifests/` | per-run SHA-256 trace hashes and parameters (`<set>_runs.jsonl`), set manifests, **validation results** (`<set>_validation.json`), clean-clone reproduction (`reproduce_check.json`), figure/table hash manifests |
| `results/figures/` | figures (PDF/PNG) with the exact plotted values (`*_data.csv`) |
| `docs/` | formal model, novelty matrix, literature verification, experiment protocol + addenda, confirmation protocol, E1-E3 and E4 protocols, development log, limitations, worked example |
| `reports/` | initial audit, validation, claim-to-evidence matrix, adversarial review rounds and responses, gate dashboard, final and independent validation reports, `independent_audit/` (audit scripts and results), `git_log.txt` |
| `paper/` | `main.tex`, `references.bib`, `generated/` (number macros and tables produced by `experiments/tables.py`), `figures/` |

**Not included:**
- Raw event traces (`results/raw/`, about 12 GB). They are regenerated byte for byte by `run_all.py`; their
  SHA-256 hashes are in `results/manifests/<set>_runs.jsonl`.
- The `.git` directory. `reports/git_log.txt` lists every commit (hash, timestamp, subject), and the full
  history can be supplied on request.

## Install and reproduce

```
pip install -r requirements.txt          # Python 3.12
python -m pytest -q                      # 131 tests
python experiments/run_all.py --set holdout          # 2,400 runs, ~10 min on 14 workers; writes results/raw/
python experiments/validate.py --set holdout --rerun 1
python experiments/analyze.py --set holdout
python experiments/reproduce_check.py --k 1          # from a fresh copy: reruns + regenerates tables/figures and compares hashes
python experiments/tables.py && python experiments/figures.py --set holdout
```

Inside a git working copy, `run_all.py` refuses to run a reported set if `src/` has uncommitted changes. Outside
git, for example in this ZIP, that check cannot run: the manifest records an empty commit and `src_dirty=false`.

## Evidence index (for auditors)

| check | where to look |

| Metric definitions | `src/dafc/metrics.py` (six exclusive outcome classes; partial and escalated never count as success); `src/dafc/groundtruth.py` |
| Data consistency | all manuscript numbers are macros in `paper/generated/numbers.tex` produced by `experiments/tables.py`; figure hashes in `results/manifests/figures_manifest.json` |
| Novelty | `docs/novelty_matrix.md` (incl. §4/§4b outcome), `docs/literature_verification.md` |
| Research integrity | `docs/development_log.md` (every decision made after seeing data), `reports/claims_evidence.md`, `reports/adversarial_reviews*.md`, `reports/reviewer_response.md`, `reports/git_log.txt` (registration timestamps) |
